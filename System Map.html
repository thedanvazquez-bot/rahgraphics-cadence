Pause triggers stop the cadence.

Every pipeline stage has a pause trigger that, when activated, switches the system from auto-cadence to a specific exception template. The architecture is: assume oversight before hostility, make the next move obvious, give easy ways to respond.

The state machine is the source of truth.

Every contact lives in exactly one state. State determines what communication happens next, what the silence threshold is, and who owns the next action. When in doubt: state first, message second.

No chasing. No fake scarcity.

Follow-ups are professional persistence followed by a clean close — never nervous checking-in, never fake urgency. Real scarcity (studio availability) is the only scarcity. Real close-loops are the only close-loops.
